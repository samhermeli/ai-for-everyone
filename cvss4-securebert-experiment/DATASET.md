# Dataset attribution

This experiment includes the compressed file `nvdcve-2.0-2025.json.gz`.
It is an unmodified gzip representation of the `nvdcve-2.0-2025.json`
file used during the experiment.

- **Source:** [Fragmentation of CVSS Scores in the NVD: A Quantitative Analysis of Inconsistency Across Vulnerability Scoring Standards](https://data.mendeley.com/datasets/5343z8zfxg/1)
- **DOI:** `10.17632/5343z8zfxg.1`
- **Contributor:** Michal Walkowski
- **Version used:** 1
- **Source licence:** [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- **Original source described by the dataset:** National Vulnerability Database (NVD) API 2.0 records retrieved in October 2025

The experiment consumes only the records with an English description and a
complete CVSS 4.0 Base vector. It does not alter or relabel the source data.
